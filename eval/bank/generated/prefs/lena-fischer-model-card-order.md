# Lena Fischer wants model cards in the order data, metrics, limitations, owner, sign-off
- Every credit model card uses five sections in this order: data, metrics, limitations, owner, sign-off.
- Metrics come second so a reader sees performance before the caveats; limitations are never moved to the end.
- A card without a named owner and a dated sign-off line is returned unread.
