# Alex Chen wants model ids written in backticks the first time they appear in a note
- The first mention of any model in a note is written as its id in backticks, e.g. `cli-xgb-v3`, with the eval set after it.
- Later mentions may use the plain name.
- Alex returns notes where a model is named only as "the new model", since two versions were confused in February.
