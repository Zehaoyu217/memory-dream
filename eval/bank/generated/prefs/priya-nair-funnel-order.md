# Priya Nair wants onboarding funnel bars in step order, not sorted by size
- The onboarding funnel chart shows steps in the order a customer meets them: application, identity check, card activation, first purchase, first statement.
- Bars are not sorted by size, because the point is where in the sequence the drop happens.
- Reason: sorting by size hid that the identity-check drop (-14 pts in 2025-09) sits before activation, which moved the fix from copy to vendor latency.
