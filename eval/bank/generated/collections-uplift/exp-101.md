# exp-101: cu-resp-v1 top 20% captures 38% of promise-to-pay events, against 20% for random
Ranking test on holdout-2025q1 (n=24,860 contacted accounts, 1-29 DPD). Recall@20% of PTP events is 0.38 for cu-resp-v1 and 0.20 for random.
Precision@20% is 0.31 against a base rate of 0.186.
Source: notebook `collections_uplift/exp101_response_rank.ipynb`, run 2025-03-24.
Read: the response model ranks well, but ranking well is the wrong test if the top ranks would pay anyway. See exp-102.
