# exp-102: T-learner uplift@20% is 0.031 on the pilot holdout, against 0.012 for the response model
Eval: pilot holdout split, treatment n=21,312 and control n=2,368 (20% of pilot). Uplift@20% is the PTP rate in the top 20% by score, treated minus control.
cu-uplift-v1: 0.031 (95% CI 0.018-0.044). cu-resp-v1 ranking the same accounts: 0.012.
Source: `collections_uplift/exp102_tlearner.ipynb`, run 2025-05-14.
Caveat: the control arm is small inside the top 20%, so the CI is wide.
