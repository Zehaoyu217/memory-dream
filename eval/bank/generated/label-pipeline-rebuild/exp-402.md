# exp-402: fraud labels arrive a median 71 days after the transaction, with the 95th percentile at 128 days
Measured on 6,100 confirmed-fraud transactions from 2024, from transaction date to the date the set A label was written.
Median lag 71 days, 95th percentile 128 days. A model evaluated at 90 days would see many fraud rows still unlabelled.
