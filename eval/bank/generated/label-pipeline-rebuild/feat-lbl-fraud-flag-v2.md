# feat-lbl-fraud-flag-v2: fraud label from reason-code categories A and B
Fraud is 1 when the dispute has a set A reason code (confirmed fraud) or a set B code (first-party friendly fraud). Built into cards.fraud_labels by the rebuilt job.
On 2025-Q2 approved transactions the fraud label rate rises from 0.41 to 0.47 percent with category B included (exp-403).
