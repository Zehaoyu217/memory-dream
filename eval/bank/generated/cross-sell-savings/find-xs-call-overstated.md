# Finding: the naive call effect of +1.8 points is mostly selection; the matched effect is +0.6
Raw open-rate gap 4.9% against 3.1%. After matching on propensity and tenure, +0.6 points, not significant.
Call-centre outreach is not a program at scale on this basis; it is worth targeting only where the effect survives (see xs-call-uplift-v1).
