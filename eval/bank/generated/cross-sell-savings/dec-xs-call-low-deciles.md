# Decision: call-centre savings outreach only to deciles 1-2, where a call adds about 1.2 points
The raw call effect (+1.8) was mostly selection. The causal estimate (+1.2 in deciles 1-2) justifies outreach only where the propensity is lowest and the call changes the outcome.
Calls to the top deciles stop for this offer.
