# Q: What is the current name for the 30-day spend sum feature? A: feat_txn_spend_sum_30d_v2.
The v1 version summed reversals as well as purchases and was retired in May 2025. The v2 definition excludes reversals.
The registry keeps both versions until no live model reads v1.
