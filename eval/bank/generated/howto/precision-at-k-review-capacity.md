# Set k from weekly review capacity, then report precision@k at that k
k is the number of accounts the fraud review team can work in a week, currently 1,800. Report precision@1800 on the OOT set beside recall@1800, which uses all positives in the scored population as its denominator (see `howto/recall-at-k-definition`). Daniel Okafor reads precision@k as the target.
