# A model enters staging only with a snapshot id, OOT metrics, PSI report and model card
Register as `<team>.<model>` in the model registry. Before staging the entry needs the training snapshot id, OOT metrics on the OOT set, a PSI report against the training data, and a model card. Aisha Khan signs off the registration.
Staging then needs two weeks of shadow scoring, and production needs Sam Lee's load test. The registry rejects an entry with no card.
