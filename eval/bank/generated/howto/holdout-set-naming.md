# Name holdouts holdout-<year>q<n> for quarters and <project>-oot-<year>h<n> for OOT sets
Quarter-based holdouts use the format `holdout-2025q4`: all accounts observed in the quarter, with labels matured. OOT sets use `<project>-oot-<year>h<n>`, named by the half-year their observation months fall in, for example `retention-oot-2025h2`.
Never reuse a name for a different date range. If the range changes, make a new name.
