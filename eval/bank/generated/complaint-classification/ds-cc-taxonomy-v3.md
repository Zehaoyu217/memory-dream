# Taxonomy v3 has 18 issue codes, with billing error split into fee and amount
Effective 2025-07-01 for complaints opened on or after that date. Billing error is split into billing error - fee and billing error - amount; all other legacy codes map one to one.
Regulator reports use the codes. The mapping file is `complaints.code_map`, maintained by compliance operations.
Split codes go live in regulator reports from 2026-04-01 (dec-cc-taxonomy-split).
