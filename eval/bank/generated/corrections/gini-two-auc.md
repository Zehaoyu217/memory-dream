# Gini = 2 x AUC - 1
The old note gave Gini = 1 - AUC. The correct formula is Gini = 2 x AUC - 1, so AUC 0.80 gives Gini 0.60 and AUC 0.50 gives 0.
Affected: the 2024 scorecard memo quoted Gini 0.20 for an AUC 0.80 model. That figure should read 0.60.
