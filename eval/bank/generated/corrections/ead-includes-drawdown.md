# EAD = balance + CCF x undrawn limit
The old note used the current balance only. EAD = current balance + CCF x undrawn limit, with CCF = 45% from the 2025 LGD/EAD model.
Affected: Q3 2025 provision EAD rose about 12%. Example: a $3,200 balance with $4,800 undrawn gives an EAD of $5,360.
