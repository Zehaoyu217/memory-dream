# Pushes add only +0.2 percent sessions in a randomised test; the push-open correlation was reverse causation
From exp-503: 214,000 accounts in a 10 percent randomised holdout, treated accounts +0.2 percent sessions over 28 days.
Accounts that already engage open more pushes. Push opens measure engagement and do not cause it, so push credit is removed (dec-ae-no-push-credit).
