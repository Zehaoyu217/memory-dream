# uplift
Uplift is the incremental effect of treatment over control: treated response rate minus control response rate, in percentage points. Any campaign file with a control group can be used to compute it.
Uplift@20% is the uplift among the top 20% of accounts by model score.
Example: treated 6.2% response, control 4.1%, uplift 2.1 pp.
