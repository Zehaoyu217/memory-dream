# observation date
The observation date is the as-of date at which features are computed for each record. For monthly models it is the first day of the statement month, and features use data up to the end of the previous month. The label window starts from the observation date.
Example: the January 2025 scoring run uses observation date 2025-01-01 and features through 2024-12-31.
