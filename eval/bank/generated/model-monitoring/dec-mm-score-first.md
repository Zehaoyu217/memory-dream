# Decision: score PSI is the primary drift signal; feature PSI becomes diagnostic
Score PSI led feature PSI on 17 of 19 incidents (exp-203), so the score is the first place to look.
Feature PSI stays on the dashboard to explain which input moved, but it no longer drives the on-call page on its own.
