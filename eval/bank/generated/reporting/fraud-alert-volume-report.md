# The weekly fraud alert report gives precision@50, precision@200 and alerts per 1,000 transactions on the latest holdout
- Precision@50 and precision@200 are computed on the latest out-of-time fraud holdout.
- Alerts per 1,000 transactions use the week's transactions from `cards.txn_daily`.
- The report is a table of four rows, one per model, with the model id in backticks.
