# Each registered model release gets a one-paragraph note: change, eval set, n and approver
- The note is one paragraph in the model's registry entry: what changed, the eval set name, n, and who approved.
- Example: "`cli-xgb-v3`: added 4 spend features; evaluated on `credit-oot-2026h1`, n = 61,400; approved by Lena Fischer."
- A release without a note is not counted as released in the monthly review.
