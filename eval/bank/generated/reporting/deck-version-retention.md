# Deck PDFs are kept for three years in the shared drive and superseded versions are never deleted
- Each published deck stays in the shared drive's `reporting/decks` folder for three years.
- Superseded versions (lower `_v<n>`) are kept in the same folder.
- Source tables are snapshotted with the deck so any figure can be re-derived.
