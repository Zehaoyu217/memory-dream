# Line charts of rates must state their baseline in the subtitle, as well as on the axis
- A line chart with a non-zero baseline still needs the baseline value on the axis, and now also a subtitle line: "Baseline: 80%".
- The earlier rule that only the axis label was needed is replaced.
- Bars still start at zero, and dual-axis charts are still not used.
