# Decks are saved as `YYYY-MM-DD_<deck>_v<n>.pdf`, with the version rising on each re-issue
- The date is the publication date; `<deck>` is the short name, e.g. `weekly-kpi` or `monthly-model-review`.
- A re-issue on the same date increments the version: `_v1`, then `_v2`.
- Superseded versions stay in the folder; they are not deleted.
