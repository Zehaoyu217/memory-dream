# Which labels should train the dispute classifier?
Analyst labels are noisy: single-analyst labels disagree with a second analyst on about one in five disputes.
Options: all labels, or only two-analyst agreement. The chosen rule is in dec-disp-labels-two-analyst.
Open for the first model; re-checked when label noise was measured in disp-find-label-noise.
