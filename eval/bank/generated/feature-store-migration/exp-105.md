# exp-105: churn retrain on store features lifts holdout AUC from 0.782 to 0.791
Retrained the v1 recipe on store features: v1's 40 features with payment lag v2 and util ratio from the store, plus feat-fsm-spend-cv-30d.
Holdout-2025q2 (n=412,000 accounts): AUC 0.791 against 0.782 for fsm-churn-xgb-v1, KS 0.43 against 0.41.
This +0.009 AUC gain is the main reason fsm-churn-xgb-v2 was built; see fnd-churn-lift.
