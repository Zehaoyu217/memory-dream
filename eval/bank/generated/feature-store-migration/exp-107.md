# exp-107: month-end rule test for util ratio, latest effective limit row vs exact month-end row
Compared the two rules on fsm_parity_sample_2025h2. The exact month-end rule (legacy) drops 1.2 percent of accounts, because limit changes on weekends leave no row that day.
The store rule (latest row on or before month-end) matches legacy for 98.8 percent of accounts; the other 1.2 percent are the accounts where legacy had no value.
Under the store rule, churn AUC on holdout-2025q2 moves by +0.002.
