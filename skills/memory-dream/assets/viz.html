The memory as a graph

Circles are projects, squares are general memory (preferences, reporting rules, terms, corrections, how-tos, saved answers); size is the number of notes. A line joins two areas that build on each other's notes or share tables, models or terms; each keeps its three strongest links, and hub tables count less. Select one to see its history below.

Project history

Each dot is a note, placed by kind and date. Blue lines: built on (from:). Dashed: replaced by a newer note; hollow, struck dots are history. Dotted: mentions. Select a dot to read the note.
